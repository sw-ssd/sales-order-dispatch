## 7. 接手／重做指引

### 7.1 回退方式

本輪全部改動都在 **Pixso 文件內**，沒有任何程式碼檔案被修改。回退請用 Pixso 的復原（⌘Z）或設計檔版本歷史，勿從本文件反推重建。

### 7.2 工具與環境

- 使用 Pixso 桌面版 MCP：`eval_script`（Pixso Plugin API）為主，逐項「讀取 → 寫入 → 讀回驗證」
- 未使用 `apply_design` DSL 路線；僅在需要新節點時用 `pixso.createFrame()` + `insertChild`

### 7.3 實作時踩到的 Pixso API 限制（重要）

1. **autolayout 子節點的 `width` / `height` 直接賦值無效**，要用：
   - 交叉軸伸縮：`node.layoutAlign = 'STRETCH'`
   - 主軸撐滿：`node.layoutGrow = 1` 或 `node.layoutSizingHorizontal/Vertical = 'FILL'`
   - 文字框換行：`textAutoResize = 'HEIGHT'`（固定寬自動高）
2. **`createFrame()` 建立的節點必須先 `insertChild()` 進父層**，才能設 `layoutPositioning = 'ABSOLUTE'` 或 `layoutGrow`（先設會丟錯／被忽略）
3. **要插在特定位置**用 `parent.insertChild(index, node)`；尾巴留白用空 frame + `layoutGrow = 1`（`fills = []`）
4. **複製既有列**：`row.clone()` → `parent.appendChild/insertChild` → 以 `collect(clone, n => n.type === 'TEXT')` 依序改 `characters`；注意各表欄位索引不同（客戶表首欄是勾選框，訂單表沒有）
5. 匯出檢視：`get_export_image`（得到 localhost 暫存 URL）→ `curl -o` 下載 → `view_images` 檢視；`take_screenshot` 的 base64 不易在對話中檢視
